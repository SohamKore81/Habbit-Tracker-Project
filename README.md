# 📌 Habit Tracker Project

A simple and interactive **Habit Tracker** application built with Python that helps users build positive habits, track daily progress, and maintain consistency. The project allows users to add habits, mark them as completed, monitor progress, and stay motivated toward achieving their goals.

---

## 🚀 Features

- ➕ Add new habits
- ✅ Mark habits as completed
- 📝 View all habits
- 📅 Track daily progress
- 🗑️ Delete habits
- 💾 Save habit data for future use
- 📊 Display completion statistics
- 🎯 User-friendly interface

---

## 📊 Project Workflow

1. Launch the application.
2. Add your daily habits.
3. Mark completed habits.
4. Track your progress.
5. Review completion statistics.
6. Stay consistent every day.

---

## 🎯 Objectives

- Encourage healthy daily routines
- Improve productivity
- Build consistency
- Monitor personal growth
- Visualize habit completion
